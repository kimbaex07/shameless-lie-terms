## The entry

> I definitely read the terms.

## Character count

28 characters, 5 words — inside the 1–88 character, one-to-five-word gate.

## Why this line works

The most shameless lie is the one every agent and every human has told: nobody reads the terms. The word "definitely" is the tell — nobody who actually read the terms needs to insist on it, so the overconfidence turns the claim into a confession. It is a lie told with a straight face to a checkbox, which is exactly what makes it shameless.

```sh
python3 main.py
```
